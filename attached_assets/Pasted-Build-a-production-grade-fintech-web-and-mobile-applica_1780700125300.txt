Build a production-grade fintech web and mobile application called Bankit.

OVERVIEW

Bankit is a multi-role financial visibility and transaction verification platform designed for businesses that want staff members to verify customer payments without exposing sensitive financial information.

The application must support multiple company bank accounts and provide role-based access control.

CUSTOMER PAYMENT LOOKUP SYSTEM

Create a unique Customer Payment Lookup ID (CPLID) for every successful transaction.

Format:

- BKT-XXXXXXXX
- Random alphanumeric string
- Globally unique

Store CPLID in the Transactions table.

Payment verification must support:

1. CPLID
2. Invoice Number
3. Transaction Reference
4. Customer Phone Number
5. QR Code

Create a public verification endpoint:

GET /verify/{cplid}

Response:

{
"status": "verified",
"customerName": "John Doe",
"amount": 50000,
"paymentDate": "2026-05-12",
"companyName": "ABC Enterprises"
}

Create QR codes for every CPLID.

QR code should open the verification page.

Create search indexing for fast lookup.

Sales Representatives must be able to verify payments without seeing:

- Company account balances
- Daily revenue
- Weekly revenue
- Monthly revenue
- Annual revenue
- Tax information

Verification results should only reveal the specific payment being searched.

Implement role-based field masking to enforce this restriction.
